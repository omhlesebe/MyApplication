Description
A simple Android quiz application that tests the user on cybersecurity myths and facts. The app shows a question, and the user must decide if it's a hack or a myth.

Features
- Welcome screen with start button
- Quiz questions with True/False or Hack/Myth options
- Score tracking
- Result screen

How to Run the App
1. Clone the repository: https://github.com/omhlesebe/MyApplication
2. Open in Android Studio
3. Click Run (green play button)

Tech Stack
- Kotlin / Java
- Android Studio
- XML Layouts
